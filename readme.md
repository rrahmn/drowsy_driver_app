## Project Overview

This project is a web application for detecting drowsy drivers. It utilizes computer vision techniques to analyze facial expressions and detect signs of drowsiness in real-time. The application aims to improve road safety by alerting drivers when they show signs of fatigue.

## Prerequisites

To run this project, you will need the following dependencies:

- Python 3.7 or higher

## Installation

1. Clone the repository to your local machine by running the following command:
   ```
   git clone https://github.com/rrahmn/drowsy_driver_app.git
   ```
2. Install Python 3.7 or higher if you haven't already.
3. Create and activate a virtual environment by running the following commands:
   ```
   python -m venv drowsy_driver
   source drowsy_driver/bin/activate
   ```
4. Install the required libraries by running the following command:
   ```
   pip install -r requirements.txt
   ```

## Usage

1. Navigate to the project directory.
2. Run the following command to start the web application:
   ```
   python app.py
   ```
3. Open your web browser and go to `http://127.0.0.1:5000/`.
